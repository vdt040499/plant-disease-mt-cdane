Everything except L_cons

  • Same SEED = 42, same weight initialisation

  • Same batch order (seed_loader_epoch(seed, epoch))
  • Same test split: 40 percent of PPD, fixed by seed
  • Same selection rule: source validation loss, epoch 250 onwards

Mean Teacher

What the coral marks

  • Target dataset returns three views instead of one
  • Teacher is an EMA copy of the student, gradients frozen, kept in .train() so its BatchNorm buffers stay current
  • L_cons is the softmax MSE between student(v1) and teacher(v2)
  • w(t) ramps late: zero until epoch 100, 9.0 by epoch 150
  • Model selection reads the teacher, not the student
